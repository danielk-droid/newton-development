# Newton Development content standards

- Public-facing copy must use direct, professional source and provenance language.
- State where information comes from rather than defending how it was produced.
- Avoid phrases that tell readers information was not guessed, invented, made up, or manually estimated.
- When presenting a verified project fact, include a specific source URL whenever the data model supports one.
- Prefer omitting an unsupported fact over filling space with uncertain information.
- Preserve these standards when adding future projects, project descriptions, map copy, event copy, or automated data displays.
